# Trace Codex Workflow

The user works on Trace during short breaks and must close the Windows laptop lid when returning to work. Closing the lid may suspend or interrupt Codex rather than cancel the task. A long pause or reconnecting message may simply mean the laptop is asleep or reconnecting.

When the user returns, inspect the current working tree and existing progress before taking action. Resume safely from the current state. Do not restart completed work or assume the task failed without checking.

Continue with remaining implementation, tests, build validation, and visual verification as appropriate. Do not commit or push unless the user explicitly authorizes it.
