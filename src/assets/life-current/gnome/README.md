# Gnome Life Current Working Set

This package contains 11 approved Gnome-theme images for Trace Life Current.

- `00-gnome-book-beginning.png` is the standalone opening image.

- `01` through `10` are the 10 images intended for recycling throughout the Life Current.

- All images are currently 1672×941 PNGs.

## File list

- `00-gnome-book-beginning.png` — 1672×941. Opening King Gnome / book image. Intro scene only; not part of the 10 recycled Life Current images.

- `01-gnome-after-book-start.png` — 1672×941. First scene immediately after the book; begins the recyclable Life Current sequence.

- `02-gnome-geometry-master.png` — 1672×941. Geometry Master seam reference for the Gnome Life Current.

- `03-gnome-marketplace.png` — 1672×941. Marketplace scene.

- `04-gnome-waterfall.png` — 1672×941. Waterfall scene.

- `05-gnome-bridge.png` — 1672×941. Bridge-focused scene.

- `06-gnome-treehouse-district.png` — 1672×941. Treehouse district scene.

- `07-gnome-town-center.png` — 1672×941. Town center / wider-path scene.

- `08-gnome-dusk.png` — 1672×941. Dusk transition scene.

- `09-gnome-night.png` — 1672×941. Night scene.

- `10-gnome-dawn.png` — 1672×941. Dawn transition scene.
